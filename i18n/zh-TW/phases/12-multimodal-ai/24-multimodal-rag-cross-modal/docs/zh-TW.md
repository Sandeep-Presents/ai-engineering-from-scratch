# 多模態 RAG 與跨模態檢索（Multimodal RAG and Cross-Modal Retrieval）

> 視覺原生文件 RAG 僅僅揭開了冰山一角。真實商業正式環境中的多模態 RAG 涉足的維度遠比文件更為寬廣——橫跨文字、影像、音訊與視訊進行聯合檢索，以驅動各種複合型真實業務：例如智慧旅遊規劃（「幫我找一家環境清幽、採光極佳的純素早午餐」）、遠端醫療分診（「什麼樣的運動傷害符合這張患部照片加這段文字主訴」）、社群電商穿搭（「找出類似這張自拍風格、且有我尺寸的成套服飾」），以及工業現場維修（「診斷這段異常引擎雜音搭配這張零件外觀照」）。2025 年發表的三篇重磅綜述——Abootorabi 等人、Mei 等人與 Zhao 等人——形式化定義了其核心子問題：跨模態檢索、多路檢索融合、生成可溯源錨定（Generation Grounding）以及多模態評測基準。本課深入解讀這些前沿綜述，並著手設計一套正式生產級的多模態 RAG 管線。

**Type:** Build
**Languages:** Python (stdlib, cross-modal retriever with fusion + grounded generator)
**Prerequisites:** Phase 12 · 23 (ColPali), Phase 11 (RAG basics)
**Time:** ~180 minutes

## Learning Objectives｜學習目標

- 設計完整的跨模態檢索體系：包含文字檢索影像、影像檢索文字、音訊檢索視訊等多元路徑。
- 深入對比三種多路檢索融合策略：分數加權融合（Score Fusion）、基於注意力的神經融合（Attention-based Fusion）與 MoE 專家路由融合。
- 說明多模態生成的可溯源錨定（Generation Grounding）：當參考資料來源混雜多種模態時，「標註引用出處」在系統層面的具體工程形態。
- 掌握 2025 年三篇經典多模態 RAG 綜述的核心分類學與關鍵技術子問題體系。

## The Problem｜問題

單一模態的純文字 RAG 如今已是高度成熟的標準範式：計算問題 embedding、計算知識區塊 embedding、檢索向量相似度、拼入 LLM 上下文。然而在多模態真實業務中，RAG 必須同時攻克四重全新挑戰：

1. 多個異質檢索頭（每個模態都需要在相互相容的幾何空間中產生 embedding 向量）。
2. 跨異質模態檢索結果的有效融合。
3. 支援混合多模態證據鏈的生成可溯源錨定標註。
4. 能夠客觀量化跨模態檢索品質的評測指標體系。

2025 年發表的多篇前沿綜述論文，最終皆殊途同歸地收斂至相同的架構分類學。

## The Concept｜核心概念

### 跨模態檢索機制

跨模態檢索指給定模態 A 的查詢（例如文字），精準召回模態 B 的目標檔案（例如影像）。工業界共存三種核心模式：

1. 共享 Embedding 空間：CLIP 與 CLAP 直接在同一個語意向量空間中產出「文字 + 影像」或「文字 + 音訊」的 embedding 向量。跨模態餘弦相似度可以直接計算。缺點是僅限於預訓練階段見過的成對模態。

2. 各模態獨立編碼器 + 跨空間轉譯器：文字編碼器與影像編碼器各自獨立，中間透過一個輕量級的空間轉譯神經網路（如 Gupta 等人的 Sen2Sen 及其他 2024 年設計）進行特徵映射。彈性極高，但系統複雜度增加。

3. 多模態 VLM 作為統一編碼器：直接抽取前沿 VLM 的深層隱藏狀態作為檢索特徵。只要 VLM 支援的模態皆可通用。表徵品質最高，但推論運算開銷最為昂貴。

工程選型準則：文字 + 影像選用 CLIP / SigLIP 2；文字 + 音訊選用 CLAP；追求極致前沿綜合精度的跨模態檢索，直接調用大尺寸 VLM 隱藏狀態。

### 多路檢索融合策略

假設你的檢索系統並行召回了 10 個異質結果：5 張照片、3 段文字說明、2 條音訊片段。該如何將它們科學整合？

分數融合（Score Fusion，最經濟）：各模態使用專屬檢索器，各自產出局部相關性得分。在各模態內部先進行分數正規化（如 Min-Max 或 Z-score），隨後依預設權重線性加權求和。極度簡潔且實務上往往非常有效。

基於注意力的神經融合（Attention-based Fusion）：將所有召回項目的特徵向量拼接在一起，透過一個輕量級注意力網路自主學習各項目的重要性權重。需要專門的監督資料進行訓練。

MoE 專家融合（MoE Fusion）：利用門控網路（Gating Network）將不同類型的查詢路由至模態特化專家。面對視覺主導的問題，門控會自發調高影像權重；面對抽象事實問題，則調高文字權重。

正式環境預設配方：採用略微偏向使用者發問主導模態的分數加權融合。若後續 A/B 測試在特定垂直領域展現出顯著收益，再行升級為 MoE 門控架構。

### 生成可溯源錨定

大語言模型在生成回答時，必須能明確標註其每一句主張各自依據了哪一條召回證據。在多模態情境下：

- 文字出處標註：標準的文字引用標籤，如 `[1]`。
- 影像出處標註：具備簡要描述的視覺引用，如 `[img 3]`。
- 音訊出處標註：精確到時間戳記的聽覺引用，如 `[audio 2 at 0:34]`。

在訓練生成器時，必須引入具備顯式溯源標註的調校資料：目標回答中的每一個事實片段皆打上對應的來源索引標籤。在推論階段，模型便能自發輸出規範的可溯源引用。

### 2025 年三大權威綜述

Abootorabi 等人（arXiv:2502.08826，《Ask in Any Modality》）：最全面的多模態 RAG 分類學綜述，完整涵蓋跨模態檢索、特徵融合與生成對齊。

Mei 等人（arXiv:2504.08748，《A Survey of Multimodal RAG》）：深入剖析各子任務基準與典型邊界失效模式，極具評測指標設計的指導價值。

Zhao 等人（arXiv:2503.18016）：專注於視覺文檔與 ColPali 家族的最新進展。

通讀這三篇綜述，能精準掌握截至 2025 年春季為止全球最前沿的多模態 RAG 技術全貌。

### MuRAG——多模態 RAG 的奠基之作

MuRAG（Chen 等人，2022）是人工智慧歷史上首個完整的多模態 RAG 系統。它從多模態知識庫中同時檢索影像與文字，並聯合生成解答，在大模型浪潮爆發前夕成功驗證了多模態檢索增強的可行性。當今的 REACT、VisRAG 與 M3DocRAG 皆是其精神續作。

### 真實生產實例：智慧旅遊規劃師

使用者提問：「幫我找一家環境清幽、採光極佳的純素早午餐。」

端到端處理管線：

1. 查詢意圖分解：「清幽環境」→ 映射至環境錄音與評論關鍵字；「純素早午餐」→ 映射至菜單文本；「採光極佳」→ 映射至店內實拍照片特徵。
2. 多路平行檢索：
   - 文字檢索：在探店評論中檢索「純素早午餐、安靜無噪音」。
   - 影像檢索：在店家照片庫中檢索帶有「明亮自然光、大片窗戶、通透感」的實體畫面。
   - 音訊檢索：在餐廳環境錄音片段中檢索「低分貝、無吵雜背景音樂」的聲音特徵。
3. 多路分數融合：為每家候選餐廳綜合計算加權後的總匹配得分。
4. 將 Top-k 家精選餐廳的所有多模態證據一併餵入前沿 VLM 生成器，輸出條理清晰且附帶影像與音訊佐證引用的最終推薦方案。

這完全超越了傳統純文字 RAG 的能力邊界。每個模態都貢獻了純文字完全無法取代的獨特物理世界資訊。

### Agent 式多跳多模態 RAG

多跳（Multi-hop）檢索機制：若初次檢索未命中高置信度的完整解答，主控 LLM 會主動重構查詢並發起二次檢索。Phase 14 的 Agent 模式在此大放異彩。典型場景：

- 初次檢索出候選店家 → LLM 發現某家環境音訊偏吵，主動下達過濾條件「噪音需低於 40 分貝」並重新檢索。
- 檢索出餐廳外觀照片 → LLM 在照片角隅發現了模糊的菜單立牌 → 主動發起二次檢索精確調用該菜單高解析度大圖 → 生成確認解答。

雖然增加了多輪交互延遲，卻能穩健處理單次檢索完全無力應對的複雜複合問題。

### 評測體系現狀

跨模態綜合評測目前仍處於演進初期。當前業界通用的代理評測指標：

- 各模態各自的 Recall@k 召回率。
- 融合後的 Top-k 綜合命中精度。
- 人工盲測的端到端滿意度。
- 實際業務轉化率（如最終促成的訂位成功率或購買下單率）。

目前尚無單一標準基準能夠同時公平評測全模態。多數前沿研究皆在特定垂直領域任務上量身設計專項評測指標。

## Use It｜實際應用

`code/main.py` 完整展示了：

- 三個模擬的異質檢索器（文字、影像、音訊），在一組共用的實體餐廳資料庫上運作。
- 分數融合引擎：支援自訂各模態的權重配比，將多路分數合成為統一排序清單。
- 生成器原型：輸出包含文字出處、照片引用與音訊時間戳記的結構化解答。
- 極簡的 Agent 多跳迴圈：當初次檢索置信度未達標時，自動重構查詢條件並重新調用檢索器。

## Exercises｜練習

1. 為遠端醫療分診設計一套多模態 RAG 架構：使用者查詢 = 傷口患部特寫照片 + 疼痛主訴文字。系統該從哪些專業知識庫中檢索何種模態的證據？

2. 分數融合本質上是簡單的加權線性加總。它存在何種無法克服的邊界缺陷，是 MoE 專家融合機制所能完美解決的？

3. 閱讀 Abootorabi 等人的分類學綜述（第 3 節）。其形式化定義的三大核心子問題為何？它們如何對應至你所負責的產品場景中？

4. 為智慧旅遊規劃師設計一套完整的評測規範書。列出能夠客觀衡量影像召回率、音訊召回率以及綜合解答正確性的關鍵量化指標。

5. Agent 式多跳多模態 RAG 每多經歷一輪往返，都會累積可觀的伺服器推論延遲。在何種難度的查詢情境下，精確度的提升才能真正抵消延遲增加帶來的體驗損失？

## Key Terms｜關鍵術語

| 術語 | 常見俗稱 | 實際意義 |
|------|-----------------|------------------------|
| Cross-modal retrieval | 「跨模態互檢」 | 給定某一種模態的查詢檢索另一種模態目標；需要共用 embedding 空間或轉譯器 |
| Score fusion | 「多路分數加權融合」 | 將各模態檢索器產出的相關性得分進行正規化後加權加總；最經濟簡單的融合方案 |
| MoE fusion | 「門控專家動態融合」 | 透過門控神經網路依據問題意圖，動態決定在當前查詢中該偏信哪一種模態的檢索結果 |
| Grounded generation | 「帶引用出處生成」 | 生成模型在輸出答案時，為每一個事實主張精準標註對應的原始多模態證據索引標籤 |
| MuRAG | 「多模態 RAG 鼻祖」 | 2022 年發表的世界首款多模態檢索增強生成架構，開創了現代多模態 RAG 體系 |
| Agentic multi-hop | 「多跳自主檢索」 | 當初次檢索置信度不足時，由主控大模型自主重構查詢條件並發起多輪反覆檢索 |
