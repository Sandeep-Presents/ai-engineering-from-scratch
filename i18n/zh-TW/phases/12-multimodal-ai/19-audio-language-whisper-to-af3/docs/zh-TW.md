# 音訊語言模型：從 Whisper 到 Audio Flamingo 3 的演進脈絡（Audio-Language Models: the Whisper to Audio Flamingo 3 Arc）

> Whisper（Radford 等人，2022 年 12 月）奠定了語音辨識的黃金標準——68 萬小時弱監督多語言音訊、極簡的編碼器—解碼器 Transformer，以及讓後續所有 ASR 論文競相引用的標準評測基準。然而「語音辨識」絕不等於「聽覺推理」。詢問「這段錄音中出現了哪些樂器」、「說話者當下流露何種情緒」或「第 3 分鐘發生了什麼異音」，需要的是真正的音訊理解與因果推理，而非單純的語音轉文字。Qwen-Audio、SALMONN、LTU 以及 NVIDIA 的 Audio Flamingo 3（AF3，2025 年 7 月）一步步建立了這套強大堆疊：保留頂級 Whisper 編碼器、外加專屬音訊 Q-Former、在大量音訊指令資料上展開訓練，並引入音訊思維鏈推理機制。本課帶你完整走通這條波瀾壯闊的技術演進脈絡。

**Type:** Build
**Languages:** Python (stdlib, log-Mel spectrogram + audio Q-former skeleton)
**Prerequisites:** Phase 6 (Speech and Audio), Phase 12 · 03 (Q-Former)
**Time:** ~180 minutes

## Learning Objectives｜學習目標

- 從連續原始波形計算 Log-Mel 頻譜圖：視窗化加窗、傅立葉變換（FFT）、Mel 濾波器組與對數壓縮轉換。
- 深入對比各音訊編碼器方案：Whisper 編碼器、BEATs 以及 AF-Whisper 混合架構，並掌握各自的最佳適用場景。
- 建構專屬音訊 Q-Former：利用 N 個可學習 query 向量對頻譜圖特徵切片進行精準交叉注意力檢索。
- 深入解釋「串接式管線（Whisper 先轉文字再交 LLM）」與「端到端音訊 LLM」在架構上的根本分野，並論證為何端到端架構在聽覺推理任務上展現出顯著的規模擴展優勢。

## The Problem｜問題

語音識別在技術上已被 Whisper 徹底解決。將音訊轉錄為文字如今已淪為隨處可得的日常基礎設施。然而，這類技術的邊界僅止於「轉錄文字」。若模型無法對它所聽到的聲音展開深層推理——時間節奏、說話者身分特徵、隱晦情感語調、音樂旋律結構、乃至環境背景噪音——單純的逐字稿根本無法支撐起真正智慧化的產品功能。

三種直觀的工程架構路線：

1. 串接式管線（Cascade）：Whisper 負責語音轉錄，隨後由純文字 LLM 對逐字稿進行文字推理。在純說話錄音場景下表現極佳；但面對背景音樂、環境聲響、多方激烈插話爭論或微妙語氣情緒時則徹底抓瞎。

2. 端到端音訊大模型（End-to-end audio-LLM）：音訊編碼器將聲音特徵直接映射為音訊 token 餵入 LLM，完全跳過中間的文字轉錄步驟。完好保留了原始聲學特徵（說話者特質、情緒共鳴、空間環境音）。但需要全新的大規模跨模態對齊與指令資料進行訓練。

3. 混合架構（Hybrid）：音訊編碼器搭配雙向文字解碼器，既能精確轉錄文字，又能直接就聲音本體進行因果推理。Qwen-Audio 與 Audio Flamingo 皆堅定選擇了此項技術路線。

## The Concept｜核心概念

### Log-Mel 頻譜圖：核心音訊輸入特徵

幾乎所有現代前沿音訊編碼器皆始於同一項基礎聲學特徵：Log-Mel 頻譜圖（Log-Mel Spectrogram）。

1. 將原始音訊重新取樣至 16 kHz 標準頻率。
2. 執行短時距傅立葉變換（STFT）：採用 25 毫秒視窗長度、10 毫秒步長滑動。
3. 計算 FFT 複數結果的絕對幅值（Magnitude）。
4. 套用 Mel 濾波器組（通常配置 80 個三角濾波器，在 0 至 8000 Hz 區間呈對數非線性排布），將物理頻率扭曲映射為貼合人類聽覺感知的 Mel 尺度。
5. 進行動態範圍對數壓縮（計算 log(1 + x)）。

最終產物：一個形狀為 (T, 80) 的二維實數特徵矩陣，其中 T 為時間影格總數。對於一段 30 秒長度、影格率為 100 Hz 的短音訊，其矩陣形狀為 (3000, 80)。

### Whisper 編碼器架構

Whisper 的編碼器本質上是一個 12 層的 ViT 風格 Transformer，它將 Log-Mel 頻譜圖視為沿時間軸展開的連續特徵向量序列。其輸出端為每個時間影格產出一個豐富的隱藏狀態向量。

在標準自動語音辨識（ASR）任務中，Whisper 的解碼器是一個交叉注意力 Transformer，以編碼器輸出為條件自回歸生成文字 token。這是經典的編碼器—解碼器架構。

而在音訊大模型（ALM）的架構中，我們將 Whisper 的編碼器特徵抽取出來，作為外部強大語言模型（如 Llama 或 Qwen）的直接輸入。典型設計為：凍結 Whisper 編碼器、加裝可訓練的音訊 Q-Former，並搭配凍結或調校的底座 LLM。

### BEATs 與專屬音訊特徵編碼器

Whisper 深度偏向人類說話語音資料。面對純音樂與複雜環境噪音時，其表徵能力明顯衰退。

BEATs（Chen 等人，2022）是一款在龐大音訊資料庫 AudioSet 上進行自我監督預訓練的專屬音訊 Transformer。在相同參數量級下，它對旋律樂器、環境異音與物理聲學事件的表徵細緻度顯著超越 Whisper。

AF-Whisper（Audio Flamingo 3 採用的混合編碼器）：在通道維度直接將 Whisper 的語意特徵與 BEATs 的聲學特徵拼接在一起作為最終輸入。Whisper 負責注入高階語言文字資訊，BEATs 負責注入微觀環境聲學特質，相得益彰。

### 音訊專屬 Q-Former

其運作模式與視覺領域的 BLIP-2 Q-Former 完全同構。一組固定數量（通常設定為 32 或 64 個）的可學習 query 向量，對音訊編碼器輸出的長時序頻譜影格進行深入的交叉注意力檢索。這組 query 最終轉化為專屬於音訊的視覺化 token，直接餵入底座 LLM 進行思考。

在特徵對齊階段：僅訓練 Q-Former 本體，在大規模音訊—文字配對語料（AudioCaps、Clotho）上計算對比損失與圖文說明生成損失。在後續指令調校階段：解凍底座 LLM 展開端到端全參訓練。

### 演進浪潮——SALMONN、Qwen-Audio 與 AF3

SALMONN（Tang 等人，2023）：「Whisper + BEATs + Q-Former + LLaMA」架構。首款展現出嚴謹跨模態聽覺推理能力的開源音訊大模型。在 MMAU 評測上取得約 0.55 的綜合基準分。

Qwen-Audio（Chu 等人，2023）：沿用類似的雙塔 Q-Former 骨架，但在更海量、更多樣的音訊語料庫上展開預訓練，並針對多輪對話進行了深度調校。MMAU 基準分推升至約 0.60。

LTU（Listen, Think, Understand，Gong 等人，2023）：專門建構了強調顯式邏輯因果推導的音訊資料集，重點探索聲音上的思維鏈（CoT）推理。

Audio Flamingo 3（AF3，Goel 等人，2025 年 7 月）：當前開源體系的絕對頂級代表。採用 80 億參數的 Qwen2-7B 作為底座大腦、Whisper-large 拼接 BEATs 作為雙核編碼器、64 個 query 的進階音訊 Q-Former，並在超過 100 萬條高畫質音訊—文字指令對話上完成訓練。MMAU 綜合評測達到驚人的 0.72，在數項關鍵子評測上直接打平頂級閉源旗艦。

AF3 同時引入了「按需啟動的音訊思維鏈」機制：模型在給出最終答案前，可選擇性輸出顯式的中間思考 token（例如「讓我先逐步辨識這段音訊中出現的各項樂器：……」）。在複雜音訊因果推理任務中，開啟思考模式能帶來 3 到 5 個百分點的顯著準確率提升。

### 串接式 vs 端到端架構深度對決

傳統串接式管線：

1. 先由 Whisper 將語音訊號強制轉錄為純文字。
2. 再交由純文字 LLM 對逐字稿進行理解分析。

此架構在「幫我摘要這段 1 小時訪談內容」的場景下表現完美無瑕。但在以下關鍵維度上則遭遇全面崩潰：
- 「這首歌傳達了何種情緒？」——情緒深植於配器、調性與人聲嘶吼中，文字根本無法表達。
- 「當前說話的是愛麗絲還是鮑伯？」——逐字稿丟失了說話者的音色指紋。
- 「爆炸聲究竟發生在第幾分第幾秒？」——逐字稿徹底抹殺了精確的物理時序時間戳記。
- 「這段音訊是真實人聲還是 AI 偽造的 Deepfake？」——辨別偽造必須仰賴高頻微觀聲學殘差，純文字無法提供任何線索。

端到端音訊大模型完好保留了物理聲學訊號。Qwen-Audio 與 AF3 能夠原生處理音樂結構、環境異音與細微人類情感。

### 2026 年正式環境選型指南

為全新的音訊理解產品規劃架構時：

- 若核心需求純粹是文字演講轉錄、會議逐字稿會議記錄，且完全不涉及音樂或情緒推理：果斷選用串接式管線（Whisper + LLM）。架構最輕快、推論最經濟。
- 若核心場景涉及音樂智慧分析、語氣情感辨識、多方發言人自動分離或複雜環境音因果推理：必須選用 AF3 或 Qwen-Audio 家族的端到端架構。功能邊界更加寬廣強悍。

串接式管線更為廉價且架構極簡；端到端架構則具備更強大的泛化能力。

### MMAU——權威音訊推理評測基準

MMAU（Massive Multimodal Audio Understanding）是 2024 至 2025 年代最具公信力的權威音訊推理評測基準：

- 涵蓋人類語音、音樂旋律與環境噪音三大領域的 10,000 道深度音訊文字問答題。
- 全量檢驗分類識別、時間軸定位、因果推導與開放式複雜問答。
- 專門精準打擊傳統串接式管線體系性無法解答的盲區題目。

當前開源最強模型（AF3）得分為 0.72；閉源頂級旗艦（Gemini 2.5 Pro、Claude Opus 4.7）約在 0.78 左右。開閉源之間的鴻溝明顯小於 VideoMME 等視訊領域，這標誌著開源音訊大模型正在以驚人的速度邁向高度成熟。

## Use It｜實際應用

`code/main.py` 完整展示了：

- 以純 Python 標準函式庫實作 Log-Mel 頻譜圖計算核心：包含漢明窗（Hamming window）加窗、樸素離散傅立葉變換（DFT）與 Mel 三角濾波器組矩陣運算。
- 音訊 Q-Former 骨架：給定編碼器輸出的長時序影格特徵，計算 Q、K、V 矩陣、交叉注意力權重，並輸出 N 個濃縮後的音訊 token。
- 在微型玩具任務上展示串接式管線與端到端音訊大模型的本質行為差異。

## Ship It｜交付成果

本課產出 `outputs/skill-audio-llm-pipeline-picker.md`。給定具體的音訊業務需求（語音轉錄、音樂標籤打標、說話者情緒判斷、多發言人日誌標註、環境異音監控），它能在串接式架構、端到端 AF3 架構以及混合雙軌方案之間給出權威的工程裁決與延遲預算表。

## Exercises｜練習

1. 針對一段長度為 30 秒的音訊剪輯，在 16kHz 取樣率、25ms 視窗長度、10ms 步長、80 個 Mel 頻帶的設定下，精確計算其產生的 Log-Mel 頻譜圖維度大小。若取樣率升級至 48kHz，該特徵矩陣的維度會發生何種變化？

2. 為何 Whisper 在純音樂旋律上的表現差強人意？相較之下，BEATs 捕捉到了哪些 Whisper 內部完全缺失的聲學維度？

3. 針對音訊 Q-Former，配置 64 個 query 相比 32 個 query，在何種複雜度的任務上才能展現出顯著的性價比？在何種情況下採用 32 個 query 是更明智的精簡選擇？

4. 閱讀 AF3 論文第 4 節關於「按需啟動思維鏈」的論述。列舉三種最能從「先思考後回答」模式中獲得巨大準確率增益的典型音訊任務。

5. 設計一個利用 AF3 輸出特徵進行多發言人自動分離標註（Diarization）的極簡工程管線。模型在遇到說話者交替轉換時，該如何透過特定的結構化標籤予以明確標示？

## Key Terms｜關鍵術語

| 術語 | 常見俗稱 | 實際意義 |
|------|-----------------|------------------------|
| Log-Mel spectrogram | 「Mel 聲學頻譜圖」 | 原始音訊經 STFT 變換並透過 Mel 濾波器組壓縮後形成的二維（時間, 頻率）特徵矩陣 |
| Audio Q-former | 「音訊特徵濃縮器」 | 透過交叉注意力將長時序音訊頻譜特徵壓縮為固定數量 query 向量的資訊瓶頸模組 |
| Cascaded | 「先轉文字再思考」 | 先由 ASR 轉錄為逐字稿、再交由 LLM 推理的串接管線；不可避免地徹底遺失原始聲學細節 |
| End-to-end | 「端到端原生音訊大模型」 | 音訊特徵藉由專屬 Q-Former 直接注入 LLM 內部進行思考；完好保留情緒與聲學細節 |
| BEATs | 「音訊界的純視覺骨幹」 | 在 AudioSet 巨量語料上進行自監督預訓練的專屬音訊 Transformer，音樂與環境音感知極強 |
| MMAU | 「權威音訊推理基準」 | 涵蓋語音、音樂與環境聲響共 10,000 道深度題目的權威評測集，為當前音訊推理黃金標準 |
| On-demand thinking | 「音訊思維鏈推理」 | 模型在產出最終回答之前，允許自主輸出中間思考推導過程，能將複雜難題準確率拉升 3 到 5 分 |
