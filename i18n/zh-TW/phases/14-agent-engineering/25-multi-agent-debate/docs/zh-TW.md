# 多 Agent 辯論與協同：心智社會

> Du 等人（ICML 2024，「心智社會 Society of Minds」）啟動 N 個獨立的大模型實例分別提出初始答案，隨後在 R 輪交鋒中相互批判反思，最終收斂出共識。該架構顯著提升了事實準確性、規則遵守度與複雜邏輯推理能力；而稀疏通訊拓撲（Sparse Topology）則在 Token 成本上徹底碾壓了全網狀結構。

**Type:** Learn + Build
**Languages:** Python (stdlib)
**Prerequisites:** Phase 14 · 12 (Workflow Patterns), Phase 14 · 05 (Self-Refine and CRITIC)
**Time:** ~60 minutes

## Learning Objectives｜學習目標

- 深入解釋辯論通訊協定：N 個提案者、R 輪交鋒、收斂至單一共識解答。
- 闡述為何多 Agent 辯論能顯著提升事實正確性、規則遵守度與邏輯推理品質。
- 掌握稀疏通訊拓撲的精髓：並非每個辯論者皆需要閱讀所有對手的完整歷史。
- 以純 Python 標準函式庫實作對照腳本化 LLM 的多 Agent 辯論，對比全網狀與稀疏拓撲在 Token 成本與準確率上的權衡。

## The Problem｜問題

Self-Refine（第 5 課）本質上是單一模型對自身的挑刺與自我修復——存在嚴重的群體思維偏見（Groupthink）風險。CRITIC（第 5 課）將批判錨定於外部實體工具——但並非所有認知任務皆具備可用的外部驗證工具。多 Agent 辯論開創了第三種全新模式：啟動多個獨立模型實例、交叉互相批判，在認知衝突與意見分歧中逐步收斂至客觀真理。

## The Concept｜核心概念

### 心智社會（Du 等人，ICML 2024）

- N 個模型實例針對完全相同的問題，各自獨立產出初始解答提案；
- 在接下來的 R 輪交鋒中，每個模型仔細閱讀其他對手的提案並提出針對性批判；
- 各模型依據接收到的反方批判，動態修正自身的答案；
- 歷經 R 輪反覆激辯後，回傳最終收斂一致的共識答案。

原始論文受限於成本，主要採用 N=3、R=2 的配置。實測表明：在困難問題（MMLU、GSM8K 數學、西洋棋合法走法驗證、人物生平傳記生成）上，增加辯論者數量與交鋒輪次能帶來顯著的準確率階梯式提升。

跨異構模型的混合辯論顯著戰勝單一模型辯論：ChatGPT + Bard 聯合激辯的表現，大幅超越兩者各自單打獨鬥的成績。

### 稀疏通訊拓撲（Sparse Topology）

《Improving Multi-Agent Debate with Sparse Communication Topology》（arXiv:2406.11776，2024–2025）實證指出：全網狀（Full-mesh）辯論並非永遠最優。稀疏通訊拓撲（星狀、環狀、軸輻狀 Hub-and-Spoke）能在大幅降低 Token 開銷的前提下，取得與全網狀完全相同的準確率。每個辯論者僅需閱讀部分對手群體的觀點。

計算開銷對比：

- 全網狀拓撲（N=5，R=3）：5 × 3 = 15 次提案，每次皆需閱讀 4 位對手的觀點 = 60 次批判運算操作。
- 星狀拓撲（N=5，R=3，包含 1 個中心節點與 4 個輪輻節點）：15 次提案，各外圍節點僅需閱讀中心節點 = 僅需 12 次批判運算操作。

### 辯論大顯身手的場景

- **事實核實**：N 個獨立提案，多方交叉覆核能大幅壓制單一模型的幻覺。
- **規則約束檢驗**：西洋棋合法走法驗證——當單一模型遺漏某條冷門規則時，對手能精準揪出漏洞。
- **開放性深層推理**：多重視角框架碰撞，逐步逼近全域最優解。

### 辯論適得其反的場景

- **延遲極度敏感的即時互動**：N × R 輪的循序串聯交鋒，會引入使用者無法忍受的高額延遲。
- **成本嚴格受限的大規模呼叫**：每道問題皆需消耗 N × R 倍的龐大 Token 預算。
- **單純的事實精確查表**：一次簡單的資料庫查詢，遠比動用五個大模型開會辯論更加便宜高效。

### 2026 年的工業級落地形態

- **Anthropic 協調者—工作者架構**（第 12 課）：帶有綜合歸納步驟的實用型辯論變體。
- **LangGraph 監督者模式**（第 13 課）：中央路由器 + 專家 Agent，可直接將辯論封裝為圖上的獨立節點。
- **OpenAI Agents SDK**（第 16 課）：Agent 之間相互移交交接控制權，進行迭代式交叉審核。
- **多 Agent 自動化評測**：結合辯論機制與評估者—最佳化者，產出極高信噪比的評測信號。

### 典型架構失效模式

- **錯誤收斂崩潰（Convergence collapse）**：所有 Agent 在首輪便迅速被某個看似合理的錯誤答案所帶偏，集體收斂至錯誤結論。解法：強制在前期設定必備的「強制反對輪次」。
- **中心節點單點故障**：在星狀拓撲中，若中心節點產生幻覺，會直接帶偏所有外圍節點。解法：輪換中心角色，或配置多個中心節點。
- **Prompt 均質化陷阱**：所有 Agent 採用完全相同的 prompt，導致大家都給出完全雷同的答案。解法：為各角色注入多樣化的角色設定或引入異構模型。

## Build It｜動手實作

`code/main.py` 以純 Python 標準函式庫實作了多 Agent 辯論引擎：

- `Debater` 類別：具備獨立觀點漂移傾向的腳本化 LLM；
- `FullMeshDebate`（全網狀）與 `SparseDebate`（稀疏）兩大執行器；
- 三道經典測試題：一題事實性、一題規則約束性、一題複雜推理題；
- 核心指標：最終共識答案、收斂所需輪次、批判運算總次數。

運行實驗：

```
python3 code/main.py
```

輸出會對照各協定的準確率與運算成本；在 3 道題目中，稀疏拓撲在其中 2 題上以顯著更低的成本取得了與全網狀完全相同的準確率。

## Use It｜實際應用

- **Anthropic 協調者—工作者模式**：適用於 2 到 3 個工作者的小型實用辯論。
- **LangGraph**：適用於需要持久化檢查點與斷點復原的多輪狀態辯論。
- **自建架構**：適用於前沿學術研究或具備特殊形式化正確性保證的極致場景。

## Ship It｜交付成果

`outputs/skill-debate.md` 能為任何業務任務產出多 Agent 辯論鷹架，支援彈性配置通訊拓撲、辯論者數量 N、交鋒輪次 R 以及最終共識收斂規則。

## Exercises｜練習

1. 實作「強制對抗規則」：在第 1 輪中，每個辯論者發出的初始提案必須彼此互不相同。觀察該規則對後續收斂速度產生了何種影響。
2. 新增基於置信度加權的聚合機制：辯論者回傳（答案, 置信度）；聚合器依置信度權重結算。該機制是否提升了最終表現？
3. 將其中一個「Agent」替換為具備截然不同觀點傾向的異構腳本模型。異構多樣性是否顯著提升了最終準確率？
4. 測量在 3 道測試題上全網狀與稀疏拓撲的實際 Token 開銷。繪製出「成本 vs 準確率」的權衡曲線圖。
5. 研讀《心智社會》原始論文。將教學玩具擴充為 N=5、R=3 的大規模辯論。哪些環節開始遭遇效能瓶頸？哪些問題的表現獲得了改善？

## Key Terms｜關鍵術語

| 術語 | 常見俗稱 | 實際工程意義 |
|---|---|---|
| Debate | 「多 Agent 互評激辯」 | N 個提案者、歷經 R 輪交叉互相批判、最終收斂得出共識解答 |
| Full mesh | 「全連接網狀」 | 每個辯論者在每輪皆必須閱讀所有對手的完整歷史觀點 |
| Sparse topology | 「稀疏通訊拓撲」 | 辯論者僅閱讀部分特定對手群體的觀點，大幅節省 Token 成本 |
| Hub-and-spoke | 「星狀軸輻拓撲」 | 1 個中央節點，N-1 個外圍節點僅與中央節點進行通訊 |
| Convergence | 「共識收斂」 | 多個獨立的辯論者逐步磨合，最終就單一解答達成一致意見 |
| Society of Minds | 「心智社會」 | Du 等人於 ICML 2024 發布的多 Agent 辯論奠基方法論 |
