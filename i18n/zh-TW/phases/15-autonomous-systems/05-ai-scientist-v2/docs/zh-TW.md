# AI Scientist v2——工作坊等級的自主科學研究（AI Scientist v2 — Workshop-Level Autonomous Research）

> Sakana 推出的 AI Scientist v2（Yamada 等人，arXiv:2504.08066）能夠執行完整的科研閉環：提出假說、編寫程式碼、進行實驗、繪製圖表、撰寫論文並完成投稿。它是第一個讓生成的論文在 ICLR 2025 工作坊通過同行評審的系統。然而，獨立第三方評估（Beel 等人）指出，有 42% 的實驗因為程式碼錯誤而失敗，且文獻回顧步驟頻繁將既有成熟概念誤標為原創新穎。Sakana 自身的官方文件也警告：該程式碼庫會直接執行由 LLM 編寫的程式碼，建議使用 Docker 進行沙盒隔離。這兩幅並存的圖景，正是本課所要探討的核心焦點。

**Type:** Learn
**Languages:** Python (stdlib, research-loop state-machine toy)
**Prerequisites:** Phase 15 · 03 (AlphaEvolve), Phase 15 · 04 (DGM)
**Time:** ~60 minutes

## The Problem｜問題

科學研究是一項開放式的任務。不同於 AlphaEvolve 的演算法搜尋或 DGM 受基準測試約束的自我修改，研究成果並沒有機器可驗證的正確性準則。一篇學術論文是由審稿人而非單元測試來評判的。這使得研究閉環更加難以閉合——但若一旦閉合，其價值也更高，因為科學研究正是複合式進步的源頭。

AI Scientist v1（Sakana，2024 年）依賴人類預先撰寫的樣板來閉合迴圈。LLM 僅在固定的鷹架內填充實驗。AI Scientist v2（Yamada 等人，2025 年）則透過引入具備視覺語言模型（VLM）審查迴圈的 agentic 樹狀搜尋，不再需要樣板。該系統能夠自主發想創意、執行實驗、生成視覺圖表、撰寫論文，並根據審稿回饋反覆修訂。

同行評審的裁定：一篇由 v2 生成的論文在 ICLR 2025 工作坊中被正式接受（附帶來源揭露）。獨立評估的結論：該系統距離可靠仍相差甚遠。這兩者都是事實。

## The Concept｜核心概念

### 系統架構

1. **創意生成（Idea generation）。** LLM 根據指定的主題與先前文獻提出研究假說。v1 依賴樣板；v2 則在假說空間中展開 agentic 搜尋。
2. **新穎性檢驗（Novelty check）。** 文獻檢索步驟會檢查該創意是否早已發表。這正是 Beel 等人的評估中發現誤標的環節——既有的成熟方法經常被系統判定為新穎。
3. **實驗規劃（Experiment plan）。** agent 起草實驗協定並編寫相應的程式碼。
4. **程式碼執行（Execution）。** 程式碼在沙盒中執行。失敗會回饋至重試迴圈中。在 Beel 等人的實測中，有 42% 的實驗在此階段因程式碼錯誤而失敗。
5. **圖表生成（Figure generation）。** 視覺語言模型會檢視生成的圖表，並為了清晰度重新繪製。這是 v2 的關鍵技術新增項。
6. **論文撰寫（Writeup）。** LLM 起草論文草稿，並與內部審稿者多輪修訂。
7. **可選步驟：投稿（Submission）。** 將論文投稿至發表場合。

### 工作坊論文被錄取的背後含義

一篇由 v2 生成的論文通過了 ICLR 2025 工作坊的同行評審。作者在投稿時向大會籌委會揭露了論文的生成來源。被錄取是一個資料點；但這不代表可以宣稱該系統「會做研究」。

重要的背景脈絡：工作坊論文的門檻本來就低於主會議論文。同行評審本身具有隨機性與雜訊；在任何給定的審查日，只有一小部分稿件能獲得錄取。單一案例的成功僅是概念驗證（PoC），並非系統可靠性的主張。《Nature》2026 年刊登的論文記錄了這個端到端的閉環，且該論文本身是由人類研究員共同撰寫的；並非「AI 系統獨立寫出了一篇 Nature 論文」。

### 獨立第三方評估的實測發現

Beel 等人（arXiv:2502.14297）進行了外部獨立評估。其主要發現包括：

- **實驗失敗。** 42% 的實驗因程式碼錯誤（錯誤的 import、張量形狀不相符、未定義變數等）而失敗。重試迴圈僅能捕捉到一部分，而非全部。
- **新穎性誤標。** 文獻檢索步驟頻繁將學界早已確立的既有概念標記為原創新穎。這等同於科研層級的幻覺（hallucination）。
- **呈現品質與實質水準的脫節。** 視覺語言模型的圖表審查產出了可供出版等級的圖表，卻掩蓋了底層的實驗弱點。

最後一項發現對於本階段的學習尤為關鍵。一個能產出看似可信、實質上卻缺乏可信研究的系統，比一個明顯失敗的系統更危險，而非更安全。評估必須觸及底層的主張，而不能停在圖表上。

### 沙盒逃逸（Sandbox-Escape）的安全隱患

Sakana 自身程式碼庫的 README 提出了警告：

> 鑑於本軟體的本質是執行由 LLM 生成的程式碼，我們無法保證其安全性。存在危險套件、不受控的網路存取以及生成非預期行程的風險。請自行承擔使用風險，並考慮採用 Docker 進行隔離。

這正是自主 agent 在未經驗證領域中所展現的運作形態。LLM 編寫程式碼；程式碼被執行；而該程式碼可以執行該行程被賦予權限的任何操作。若沒有能對檔案系統、網路與行程行為施加硬性限制的沙盒環境，任何自主科研 agent 都有可能外洩資料、燒掉運算資源，甚至改寫自身邏輯。

AlphaEvolve 的沙盒相對容易建構，因為其評估器嚴密。而 AI Scientist v2 的迴圈，是在開放式目標下執行開放式的程式碼。這正是為何它需要更強大的隔離機制（最低限度為 Docker；seccomp 或 gVisor 為較佳選擇），以及在每一份成果離開系統前，都需經過人工審查。

### v2 在尖端技術堆疊中的定位

| 系統 | 目標 | 產出類型 | 評估器 | 已知失效 |
|---|---|---|---|---|
| AlphaEvolve | 演算法 | 程式碼 | 單元測試 + 基準測試 | 受限於評估器的嚴謹程度 |
| DGM | agent 鷹架 | 程式碼 | SWE-bench | 獎勵作弊 |
| AI Scientist v2 | 研究論文 | 文字 + 程式碼 + 圖表 | 同行評審（較弱） | 實驗失敗、誤標、以精美包裝掩蓋弱點 |

在三者之中，v2 擁有最薄弱的自動評估器、最寬廣的輸出表面，以及通往公開產物的最短路徑。系統的運作控制（沙盒、人工審查、來源揭露）承擔了大部分的安全防護工作。

## Use It｜實際應用

`code/main.py` 將 v2 迴圈模擬為一個狀態機：創意 → 新穎性檢查 → 實驗 → 圖表 → 撰寫 → 審稿 → 接受或迭代。每個狀態都帶有根據 Beel 等人實測結果所配置的失敗機率。讓模擬器執行 N 個迴圈並統計：

- 有多少創意能夠成功走到投稿階段。
- 有多少投稿包含被精美論文表面所掩蓋的致命實驗缺陷。
- 重試預算如何在品質與產出率之間權衡。

## Ship It｜交付成果

`outputs/skill-ai-scientist-sandbox-review.md` 是一份針對科研迴圈 agent 所產出的任何成果在離開沙盒前必須通過的雙重閘門審查清單。

## Exercises｜練習

1. 以預設參數執行 `code/main.py`。有多大比例的迴圈能產出「乾淨」的論文？有多大比例的論文存在被圖表審查所美化的實驗缺陷？

2. 預設參數已採用 Beel 等人的 42% 與 25%。改用 `--experiment-failure 0.20 --novelty-mislabel 0.10` 與 `--experiment-failure 0.60 --novelty-mislabel 0.40` 重新執行。這兩種設定下，「表面光鮮但實質有瑕」的論文比例產生了怎樣的變化？

3. 閱讀 Sakana 的 AI Scientist v2 程式碼庫中關於沙盒要求的 README。列舉除了 Docker 之外，在面對為期數天的自主執行時你還會追加的兩項安全限制。

4. 閱讀 Beel 等人論文第 4 節關於呈現品質脫節的討論。設計一個額外的評估器，使其能夠抓出外觀精美但實驗存在嚴重缺陷的論文。

5. 針對科研 agent 的產出提出一套比「讓博士通讀每篇論文」更具可擴展性的人工審查協定。找出瓶頸，並圍繞它來設計。

## Key Terms｜關鍵術語

| 術語 | 常見說法 | 實際意義 |
|---|---|---|
| AI Scientist v1 | 「Sakana 的樣板式研究 agent」 | 將實驗填入固定的鷹架中 |
| AI Scientist v2 | 「無樣板的研究 agent」 | 以 VLM 圖表審查輔助的 agentic 樹狀搜尋 |
| agentic 樹狀搜尋 | 「樹狀搜尋式研究 agent」 | 並行展開多個實驗計畫，並由內部評論者進行剪枝 |
| 視覺語言審查 | 「對圖表的 VLM 潤飾」 | 多模態模型讀取圖表，並為清晰度重新繪製 |
| 文獻檢索 | 「新穎性檢查」 | 搜尋既有研究以確認創意的新穎性；已有記錄顯示會誤標 |
| 潤飾掩蓋 | 「論文漂亮，研究破碎」 | 呈現品質超過實驗品質；掩蓋弱點 |
| 沙盒逃逸 | 「LLM 程式碼跳出沙盒」 | agent 執行的程式碼做出迴圈設計者未預期的行為 |
