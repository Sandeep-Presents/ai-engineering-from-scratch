# 視覺語言多任務預訓練（Vision-Language Pretraining）

> 編碼器、投影層與解碼器已經全部組裝就緒。現在，我們將它們深度串聯並開展聯合預訓練。兩大核心目標驅動著神經網路的共同進化：**對比式圖文對齊損失（InfoNCE）**負責在 joint embedding space 中拉近匹配的圖文配對；**自回歸語言模型損失（LM Loss）**則命令解碼器為每一張影像自主生成精確的圖說。雙劍合璧，賦予模型雙重超能力：既能為圖說精準檢索匹配的影像，又能為輸入的影像生成流暢生動的文字描述。

**Type:** Build
**Languages:** Python
**Prerequisites:** Phase 19 lessons 30-37 (Track B foundations)
**Time:** ~90 minutes

## Learning Objectives｜學習目標

- 在包含 N 組「圖片-圖說」配對的 Batch 批次維度上，實作雙向 InfoNCE 對比損失函式。
- 將對比檢索損失與自回歸語言建模損失進行多任務聯合加權組合。
- 在零外部資料集下載依賴的前提下，以純合成資料建置包含 200 組圖文對的自包含模擬語料庫。
- 運作 50 步微型端到端預訓練迴圈，親眼見證兩路損失函數呈現健康平穩的雙向下降。

## The Problem｜問題

一個真正合格的視覺語言模型必須同時掌握兩大核心生存技能。第一，它必須具備卓越的**檢索排序能力**：給定一段文字圖說，能從許多影像中精準定位並挑選出最吻合的那一張；第二，它必須具備強大的**內容生成能力**：給定一張全新影像，能像人類作家一樣有條不紊地逐字吐出詳細的圖像描述。僅僅針對單一技能進行預訓練，產出的只不過是半身不遂的殘缺系統：OpenAI 的初代 CLIP 在檢索排序上登峰造極，但它天生沒有解碼器，根本無法開口描述圖像；GPT-4V 擁有驚人的圖說生成能力，但其底層使用獨立的檢索預測頭來處理圖文匹配。多任務聯合預訓練能在單次前向傳播中一箭雙雕，同時習得這兩種能力。

InfoNCE 對比損失專門攻克檢索排序：在包含 N 個圖文對的批次中，模型將 N 個完全配對的樣本視為正例，將其餘 `N^2 - N` 個錯配樣本視為負例，並在最終產出的 `(N, N)` 相似度矩陣上計算雙向交叉熵。而語言模型損失則負責攻克生成：在以影像特徵為條件的前提下，執行標準的 next-token prediction。這兩種損失皆完全可導，且能在反向傳播中共同更新編碼器、投影層與解碼器權重。

## The Concept｜核心概念

```mermaid
flowchart TB
  Batch[N 組影像－圖說配對] --> Enc[視覺編碼器]
  Batch --> Tok[將圖說 Token 化]
  Enc --> Pool[CLS 池化 + 投影]
  Tok --> TxtEnc[文字編碼器平均池化]
  Pool --> ImgEmb[影像 embedding 向量 N x D]
  TxtEnc --> TxtEmb[文字 embedding 向量 N x D]
  ImgEmb --> Sim[相似度矩陣 N x N]
  TxtEmb --> Sim
  Sim --> CL[雙向 InfoNCE]
  Enc --> Dec[交叉注意力解碼器]
  Tok --> Dec
  Dec --> LM[語言建模交叉熵]
  CL --> Total[對比損失 + LM]
  LM --> Total
```

### 一段話透視 InfoNCE 核心數學

將批次中的 N 個 image embedding 向量堆疊為矩陣行，將 N 個 text embedding 向量堆疊為矩陣行。對兩者分別實施 L2 範數歸一化。計算 `N x N` 相似度矩陣 `S = I T^T / tau`（其中 `tau` 為可學習的溫度係數）。主對角線上的條目代表真正匹配的圖文正例；對角線以外的所有非對角條目皆為負例。沿著行方向套用交叉熵損失，以 `argmax` 為目標，要求第 `i` 行的最大值必須精確出現在第 `i` 列；隨後對稱地沿著列方向再套用一次交叉熵。兩者的算術平均數即為最終的雙向 InfoNCE 損失。這就是名震天下的 CLIP 損失函數，在程式碼中僅需 8 行即可優雅表達。

### 溫度係數生死攸關

溫度係數 `tau` 嚴格掌控著 Softmax 機率分佈的尖銳程度。若設定得過小（例如 `tau = 0.01`），Softmax 分佈將極度尖銳，反向傳播梯度幾乎完全被最難的那一個單一負樣本所霸佔，引發劇烈震盪的梯度雜訊；若設定得過大，Softmax 分佈將被徹底撫平，梯度衰減消失。CLIP 將 `tau` 作為可學習參數進行端到端最佳化；本課的演示程式同樣完全比照該做法。

### 自回歸語言模型損失

解碼器透過交叉注意力持續汲取影像特徵記憶，並在文字序列的每一個位置自回歸預測下一個 Token。損失計算採用標準的交叉熵，標籤為向左錯位平移一位的文字 Token。對應 Padding 填充的所有位置皆不納入損失計算。

### 損失的多任務動態加權

全局總損失定義為：`total = contrastive + lm_weight * lm`，其中 `lm_weight` 為平衡標量（通常設定為 1.0）。兩路損失在反向傳播時共同將梯度注入視覺編碼器與跨模態投影層；而文字解碼器則專門接收來自 LM 損失的專屬梯度。這正是 CoCa、BLIP 與 SigLIP 等全能模型所廣泛依託的多任務配方。

| 核心損失元件 | 作用的損失空間表面 | 實質影響的子網路模組 |
|---|---|---|
| InfoNCE 對比損失 | 聯合語義空間中的圖文對排序 | 視覺編碼器 + 投影層 + 文字編碼頭 |
| LM 語言模型損失 | 以影像為條件的 next-token prediction | 視覺編碼器 + 投影層 + 文字解碼器 |
| **Combined 聯合損失** | **多任務端到端協同** | **整套多模態神經網路堆疊** |

### 為何 50 步已足夠演示

本課提供的模擬語料是由隨機圖片與隨機圖說 ID 組成的 200 對合成資料。在批次大小為 16 的配置下，執行 50 步 SGD 更新後，即使絕對值仍高於真實資料模型可達到的水準，兩路損失仍會明顯下降。演示的目的在於確認梯度路徑能端到端順暢運作，且加入 LM loss 不會使對比目標不穩定。

## Build It｜動手實作

`code/main.py` 實作了以下核心模組：

- `MultimodalModel`：完整整合微型 ViT 編碼器、MLP 投影層、文字編碼頭（對 embedding ID 實施平均池化），以及第六十一課打造的交叉注意力文字解碼器。
- `info_nce_loss(image_emb, text_emb, temperature)`：雙向對稱的 CLIP 風格 InfoNCE 核心對比損失。
- `lm_loss(logits, target_ids, padding_id)`：帶有 Padding 遮罩的 next-token cross-entropy 損失。
- `make_mock_corpus(seed, n_pairs)`：確定性合成 200 組包含（圖片, 圖說 ID）的自包含測試語料。
- 核心訓練迴圈：配置批次大小為 16，使用 Adam 最佳化器與可學習的 Log-temperature 參數，連續執行 50 步預訓練，每隔 5 步即時印出兩路損失走勢。

執行測試：

```bash
python3 code/main.py
```

輸出結果：驗證對比損失從初始的約 `ln(16) = 2.77` 穩定降至 2.4 附近；LM 語言模型損失自隨機均勻分佈的 `ln(512) ≈ 6.24` 大幅暴跌至 4.7 附近。兩路損失的持續下降確鑿證明了梯度拓撲連線完全正確。真實模型運作數百萬步預訓練，其底層動力學與此完全同構。

## Use It｜實際應用

完全相同的多任務損失配方廣泛統治著以下經典工業級模型：

- **CLIP（2021）**：純粹的圖文對比學習，另搭配一個使用凍結編碼器的圖說生成探針。
- **CoCa（2022）**：在一套統一模型中同時塞入圖文對比與圖像描述 LM 損失。這正是本課所親手建構的完全同一架構。
- **BLIP 與 BLIP-2**：對比損失 + LM 損失 + 圖文匹配（ITM）二分類頭，三重損失聯合驅動。
- **SigLIP（2023）**：將 InfoNCE 升級為逐對計算的 Sigmoid 損失；扮演相同的對比角色，但函數形式不同。
- **LLaVA 家族**：兩階段訓練——第一階段對齊（在凍結的 LM 上訓練投影層，對應第六十課）；第二階段解凍 LM 並全面開啟多模態 LM 損失（對應本課）。

## Exercises｜練習

1. 將 InfoNCE 損失替換為 SigLIP 風格的 Sigmoid 成對損失，在完全相同的模擬語料庫上對比兩者的收斂動態。
2. 引入難負樣本挖掘（Hard-Negative Mining）機制：每隔一個批次，挑選上一批次中預測最為混淆的非對角線負樣本強行追加進當前批次中。觀察對比損失的下降速率是否顯著加快。
3. 在 joint embedding space 頂部追加一個圖文匹配（ITM）二分類預測頭（判定輸入圖文是否為真實配對），引入第三路交叉熵損失，完美復現 BLIP 的經典三頭結構。
4. 將純隨機合成的圖說 ID 替換為馬可夫鏈（Markov Chain）生成的結構化文字（其轉移機率矩陣與影像的雜湊值相關聯）。觀察 LM 損失是否能進一步暴跌，因為資料中含有可學習的影像條件訊號。
5. 分別在 `lm_weight = 0` 與 `lm_weight = 1` 兩種模式下訓練模型。對比兩者的對比損失收斂情況，觀察 LM 損失是否使排序目標退化。

## Key Terms｜關鍵術語

| 術語 | 核心定義 |
|---|---|
| InfoNCE | 雜訊對比估計損失：在圖文相似度矩陣上實施的雙向交叉熵損失 |
| Temperature（溫度係數） | 控制對比 Softmax 機率分佈平緩與尖銳程度的關鍵標量超參數 |
| Hard negative（難負樣本） | 模型極易發生混淆、在特徵空間中與錨點極為接近的錯誤負例配對 |
| LM loss（語言模型損失） | 在影像特徵條件約束下，文字解碼器端進行的 next-token prediction 標準交叉熵損失 |
| Joint embedding space | image embedding 與 text embedding 投影後共同所在、可直接比較餘弦相似度的高維幾何空間 |
